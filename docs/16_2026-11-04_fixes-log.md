# Fixes log

**Date:** 2026-11-04

A short record of problems found and how they were fixed, so you can compare the fix with other ways to solve the same problem. Newest first. Feature work goes in [the build notes](06_2026-11-04_build-notes.md); this file is only for problems.

Each entry says:
- **Problem:** what was wrong, as you saw it
- **Fix:** what changed, and whether it was code, art or data
- **Other ways:** how other developers often solve it, and why we didn't (or might later)

---

## 2026-11-04: Hard grass squares around objects

**Problem:** after tilling a big field, the grass left under the stall, house, well and lanterns showed as hard green squares, because tiles meet in straight lines along the grid.

**Fix (code, plus an image made by a script):** a new `SoilEdges` node draws ragged bits of grass over the edge of any soil tile that touches grass, so the border wobbles like a real field. The bits are cut from the existing grass texture by `tools/build_curse_edges.gd`, the same trick already used for the curse border, so no new art was needed. Both now share one base script, `TileEdges`.
- Files: `scripts/farm/tile_edges.gd`, `soil_edges.gd`, `curse_edges.gd`, `assets/tiles/grass_edge.png`

**Other ways:**
- **Transition tiles (autotiling), the most common way.** An artist draws extra tiles for every edge and corner (a set of 16 or 47 pieces), and Godot's TileMap *terrains* pick the right piece from the neighbors. It looks the best when hand-drawn, but it needs that art, and AI images rarely line up well enough across 16 to 47 pieces.
- **A base sprite under each object:** a patch of dirt or stone under the stall. It only fixes objects, not every field edge.
- **Don't allow tilling right beside buildings,** leaving a path. A good idea for later for layout, but it doesn't fix the edges either.

## 2026-11-04: Tilled soil could never be removed

**Problem:** once ground was tilled it stayed soil forever, so after playing a while the whole shore was brown.

**Fix (code and one data number):**
- The Hoe on empty soil (no crop) turns it back into grass.
- Soil with no crop for 3 nights turns back into grass by itself. The number is `soil_idle_nights` in `data/balance.tres`, and each tile's night count is saved.
- Facing empty soil shows "Empty soil: grass returns in 3 nights.", so the rule isn't a surprise.
- Files: `scripts/farm/farm.gd`, `game_balance.gd`

**Other ways:** most farming games do the same: unplanted soil slowly turns back to grass overnight, sometimes by random chance instead of a fixed count. A fixed count is easier to understand and to test. Some games also add a separate tool (a pickaxe or shovel) to clear soil, but reusing the Hoe keeps one less tool to learn.
