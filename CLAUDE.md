## Game
- Moody dark-fantasy 2D top-down farming game: farming heals a cursed island (concept: `docs/03_2026-11-03_game-concept.md`)
- Built in layers: farming → curse/cleansing → collect/craft → build → combat → mobile/release
- Current layer plan: `docs/01_2026-11-03_layer-1-farming.md`; read it before adding gameplay features
- Art: AI-generated 32×32 pixel art, prompts in `docs/02_2026-11-03_art-prompts-layer-1.md`; use colored placeholders until an asset exists
- Lighting: art is neutral daylight; mood comes from `CanvasModulate` and `PointLight2D`, never baked into sprites

### How the game works now
- **Player** (`scripts/player/player.gd`, `scenes/player/player.tscn`): 8-way movement, 4 facing poses (`Player.Facing`), feet collision 20×10, `Reach` Area2D. Tools `Player.Tool` (HOE, WATERING_CAN, SEEDS, HAND) on keys 1–4, Q/E pick seed (`seed_index` into `GameState.CROPS`). Signals `tool_changed`, `tool_used(tool)`. F calls `interact(player)` on the first overlapping area that has that method
- **Animation**: idle sheet `assets/player/player_idle.png` (4 frames 48×64: down, up, left, right); walk sheets `walk_down/up/side.png` (4 frames, 8 fps, exported on Player; side faces left, right = `flip_h`). A direction without walk art falls back to idle + bob
- **Map**: 40×26 tiles; clean shore (rough ellipse) surrounded by cursed ground that blocks walking. `scenes/farm/ground.tscn` is generated by `tools/build_farm_map.gd` (also builds `data/tilesets/ground_tileset.tres`: sources 0 grass, 1 cursed with collision, 2 soil dry, 3 soil wet). Rerunning overwrites hand painting
- **Ground textures** are 128×128 (4×4 tiles); each cell uses the piece at (x mod 4, y mod 4) via `Farm.texture_coords()`
- **Farm** (`scripts/farm/farm.gd`, node `Main/Farm` with Ground, Soil, Highlight): farm area `Rect2i(13, 9, 12, 10)`; target cell = tile in front of the feet; `can_use(tool, cell)` drives the highlight (white = usable, red = not) and `_on_tool_used`. Tilled = a Soil layer cell; watered = SOIL_WET source. `crops: Dictionary[Vector2i, Crop]`, crop nodes go in the y-sorted `World`. Hand tool on a ripe crop calls `harvest(cell)`; the soil stays tilled so the cell can be replanted
- **Crops**: `CropData` resources in `data/crops/` (radish 3 days, carrot 5, pumpkin 8; seed and sell prices set), listed in `GameState.CROPS`. `Crop` (`scenes/farm/crop.tscn`): `days_grown`, stage = days × 3 / days_to_grow, `is_ripe()`. Frames: radish 32×32, carrot 32×40, pumpkin 40×32 (kept at real pixel size; the sprite offsets by texture height)
- **Days**: house door (`scenes/farm/house.tscn`, Door Area2D) → `GameState.request_sleep()` → HUD fades out → `GameState.end_day()` emits `day_ended` (Farm grows watered crops, dries all soil) then `day_started`
- **GameState** autoload (`scripts/autoload/game_state.gd`): `day`, `money`, `seeds` (start: radish 10, carrot 5, pumpkin 3), `harvest` (`harvest_count()`, `add_harvest()`), signals `inventory_changed`, `sleep_requested`, `day_ended`, `day_started`
- **HUD** (`scripts/ui/hud.gd`): hint line, day, money and inventory labels (top right; one line per crop: harvested count and seeds), tool/seed label, fade rect. `_refresh()` runs on `inventory_changed`, so emit that when money changes
- **Main scene**: Main → Farm (Ground instance, Soil, Highlight), World (y-sorted: House at (912, 288), Player, crops), HUD

## Display and input
- Base resolution 640×360 (20×11 tiles of 32px), window 1280×720, stretch mode `canvas_items` (not `viewport`: that made movement jump in 2-pixel steps), integer scaling
- Texture filter Nearest, 2D transforms snap to pixel
- Physics interpolation ON (smooth movement on 120 Hz+ monitors with 60 Hz physics); cameras use the physics process callback
- Input actions (in `project.godot`): `move_up/down/left/right`, `tool_1`–`tool_4`, `seed_prev`, `seed_next`, `use_tool`, `interact`

## Folder layout
- `scenes/`: `.tscn` scenes by feature (main/, player/, farm/, ui/)
- `scripts/`: `.gd` scripts mirroring `scenes/`, plus `autoload/`
- `data/`: game data (crop definitions, prices)
- `assets/`: tiles/, crops/, items/, tools/, objects/, player/ (game-ready art at real pixel size, don't read)
- `art_source/`: original AI images from ChatGPT (ignored by Godot via `.gdignore`)
- `tools/`: dev scripts, ignored by Godot. `build_farm_map.gd` builds the tileset and ground scene. `pixelize.gd` shrinks AI art to real pixel size: `--headless --path . --script tools/pixelize.gd -- --in art_source/... --out assets/... --height 64 --frame-w 48 --frame-h 64`
- `docs/`: design and build plans (ignored by Godot via `.gdignore`); `research/`: research notes

## Code style
- GDScript with static typing (`var speed: float = 200.0`, typed function args/returns)
- snake_case for files, variables and functions; PascalCase for `class_name` and nodes
- Signals for communication between nodes; avoid deep `get_node("../../..")` paths
- Autoloads (singletons) only for truly global state (e.g. `GameState`, `AudioManager`)
- Export tunable values with `@export` so they can be tweaked in the editor
